# SurfUX Website

Complete modern PHP starter for SurfUX.

## Includes
- Expanded Home V2
- About
- Services
- Portfolio + filters
- Portfolio case-study pages
- News
- Contact
- Responsive navigation
- Home process, expertise, statistics, social showcase, testimonials and FAQ
- Auto-detected BASE_URL for XAMPP/WAMP/Laragon and PHP built-in server

## XAMPP
Extract to:
`C:\xampp\htdocs\SurfUX\`

Open:
`http://localhost/SurfUX/`

## PHP built-in server
From the SurfUX folder:
`php -S localhost:8000`

Open:
`http://localhost:8000/`

## Before production
Replace demo portfolio data, placeholder contact information and generated visual placeholders with SurfUX's real assets/content. Connect the contact form to email/API/SMTP and add final SEO/social metadata.
